# Brazo Robótico de Agarre

## Descripción del proyecto
Este proyecto corresponde a una aplicación desarrollada en **Python**, orientada al control de un **hub LEGO SPIKE Prime** mediante una **interfaz gráfica**. Está pensado para estudiantes y docentes que deseen interactuar con el robot de forma visual y sencilla, utilizando el firmware **Pybricks**.

El proyecto fue desarrollado en la **Universidad de Tarapacá (Arica)** durante el **segundo semestre de 2025**, como parte de un trabajo académico.

## Características
- Control del hub LEGO SPIKE Prime mediante Bluetooth.
- Interfaz gráfica desarrollada con Tkinter.
- Compatibilidad con firmware Pybricks.
- Control de motores y lectura de entradas.
- Ejecución del programa mediante pybricksdev.

## Tecnologías utilizadas
- Python 3  
- LEGO SPIKE Prime  
- Pybricks  
- pybricksdev  
- Tkinter  

## Requisitos
- Python 3.x instalado.
- Hub LEGO SPIKE Prime con firmware Pybricks.
- Bluetooth habilitado en el computador.
- Sistema operativo compatible (Windows, Linux o macOS).

## Instalación
- Primero, se debe instalar el firmware de Pybricks en el hub LEGO SPIKE Prime desde la siguiente página:
- https://code.pybricks.com/
- En el panel izquierdo aparece la sección “Firmware”, junto a un botón que dice “Install Pybricks Firmware”. Se debe seleccionar el hub, aceptar las licencias, asignarle un nombre y seguir las instrucciones que indica la página.
- Para Visual Studio Code, lo más recomendable es seguir la guía oficial de Pybricks:
- https://translate.google.com/translate?u=https://pybricks.com/project/pybricks-other-editors/&hl=es&sl=en&tl=es
- En VS Code, utilizando pip, es necesario instalar las librerías pybricks y pybricksdev.
- Luego en la consola escribir "cd [nombre de la carpeta de instalación]" (sin los corchetes)
- Luego escribir "git clone https://github.com/joaquinquezadaflores-cell/Proyecto-1"
- Finalmente, se debe conectar el hub por Bluetooth y ejecutar el programa desde Visual Studio Code.
## Release
- Otra opción es usar el ejecutable disponible en:
- github.com/joaquinquezadaflores-cell/Proyecto-1/releases/tag/1.0
- Compatible con Windows 11
- Siga los pasos indicados en la preparación del hub
- Luego se descarga el ejecutable "Control.para.Brazo.robotico.de.agarre.exe"
- Se ejecuta
- Se conecta el robot por bluetooth
- Se empieza a operar

## Uso básico
1. Encender el hub LEGO SPIKE Prime.
2. Conectarlo al computador mediante Bluetooth.
3. Ejecutar el archivo principal
