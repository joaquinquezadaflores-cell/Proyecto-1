# Proyecto LEGO SPIKE Prime con Pybricks

## Descripción
Este repositorio corresponde a un proyecto desarrollado en **Python** utilizando **LEGO SPIKE Prime**, realizado en la **Universidad de Tarapacá (Arica)** durante el año **2025**. El proyecto fue desarrollado a lo largo del **segundo semestre de 2025** como parte de una investigación académica.

El sistema implementa una **interfaz gráfica** desarrollada con **Tkinter**, la cual permite controlar un **hub LEGO SPIKE Prime** utilizando el firmware **Pybricks** y la herramienta **pybricksdev**.
